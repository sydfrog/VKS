How the pieces relate: Supervisor is the Kubernetes control plane embedded in vCenter/ESXi — its bundled K8s version is tied to the vCenter/vSphere patch. VKS (vSphere Kubernetes Service, formerly Tanzu Kubernetes Grid Service / TKGs) is the service that provisions guest ("workload") Kubernetes clusters running VKr (vSphere Kubernetes releases) on top of a Supervisor. Supervisor K8s version and VKS/VKr cluster versions upgrade independently.
Key rules of thumb: Supervisor minor versions must be upgraded sequentially (e.g. 1.28 → 1.29 → 1.30, no skipping). A given VKS release requires a minimum Supervisor version. Guest cluster (VKr) versions are constrained by the VKS release installed on the Supervisor.
