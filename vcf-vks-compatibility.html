How the pieces relate: Supervisor is the Kubernetes control plane embedded in vCenter/ESXi; its bundled K8s version is tied to the vCenter/vSphere patch. VKS (vSphere Kubernetes Service — formerly Tanzu Kubernetes Grid Service / TKGs) provisions guest ("workload") clusters running VKr/TKr Kubernetes releases on top of a Supervisor. cert-manager and Contour are Tanzu Standard packages (certificate automation and ingress, respectively) installed into workload clusters or as Supervisor Services; their versions come from the Tanzu Standard repository version, not from VKS directly. Avi Controller / AKO is the alternative L4–L7 load-balancing/ingress path (NSX Advanced Load Balancer) — not in use in your environment.
Upgrade rules of thumb: Supervisor minor versions step sequentially (e.g. 1.28 → 1.29 → 1.30, no skips). A given VKS release requires a minimum Supervisor version. Guest (VKr/TKr) versions are bounded by the VKS release on the Supervisor. Package versions (cert-manager, Contour) advance with the Tanzu Standard repo you point clusters at.
